# Nugrohos Music

Web musik ini adalah produk digital original milik **Nugroho Y.R.** (Yulian Nugrohos Group).

## Isi Paket

- `nugrohos_music/` — source code aplikasi web musik Nugrohos Music
- `anti-clone.js` — penanda perlindungan produk
- `LICENSE` — ketentuan penggunaan dan penjualan kembali

## Harga

- Harga asli dari pembuat (**Nugroho Y.R.**) untuk produk musik ini: **Rp20.000,-**
- Jika produk ini diperjualbelikan kembali oleh pihak lain, harga jual **wajib lebih tinggi** dari harga asli, yaitu di kisaran **Rp25.000,- hingga Rp30.000,-**
- Dilarang menjual di bawah harga asli (Rp20.000,-)

## Catatan

Detail lain seperti logo dan aset tambahan menyusul.
